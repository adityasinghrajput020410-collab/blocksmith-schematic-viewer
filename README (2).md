# Blocksmith Schematic Viewer

Drop a schematic and see it in 3D with a full material list. 100% in the browser, nothing is uploaded.

**Formats:** `.litematic` (Litematica), `.schem` (WorldEdit / Sponge v2 + v3), structure `.nbt`, legacy `.schematic` (basic block names).

**Features:** orbit/pan/zoom, layer slider (all / up to / single layer, arrow keys), material list with stacks and shulker estimate, click a row to highlight, hide non-selected, search, copy / CSV export, PNG screenshot, auto-rotate.

**Limits:** colours are approximate (no textures); stairs, slabs, doors, fences are simplified shapes; block entities (chest contents, signs) are not read.

Open `index.html` locally or host it on GitHub Pages - it is a single file.
